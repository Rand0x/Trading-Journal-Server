Trading Accounts & Broker Connectors

Manage MetaTrader 4, MetaTrader 5, and cTrader read-only synchronization

MetaTrader 4 & 5 Expert Advisor

EA Sync
Install the bundled read-only EA in each MetaTrader terminal. It sends data directly to this journal server.
1. Create the account. 2. Copy its EA API key. 3. Set the server URL and API key in the EA inputs, then add the URL under Tools → Options → Expert Advisors → Allow WebRequest.
Download MT5 EA (.mq5) Download MT4 EA (.mq4)

cTrader cBot

Local Push
Install the bundled read-only cBot in cTrader. It sends account data directly to this journal server without an Open API application or OAuth token.
1. Create a cTrader account here. 2. Copy its Journal API Key (not a cTrader token). 3. In cTrader Algo create a new C# cBot, replace its code with the download, build it, enter the Pi URL and key, then start it locally. Download cTrader cBot (.cs)

Alternative: cTrader Open API 2.0 (read-only)

Uses the cTrader Open API JSON WebSocket gateway; no terminal is required, but an Open API application and OAuth token are needed.

MetaTrader 4 & MetaTrader 5 Read-Only Synchronization

Automatically push closed trades, balance, equity, and chart candles from MT4/MT5
📥 Download MT5 EA (.mq5) 📥 Download MT4 EA (.mq4)
  1. Download the Expert Advisor file (TradeJournalSync.mq5 or TradeJournalSync.mq4).
  2. Open MetaTrader, click File ➔ Open Data Folder, navigate to MQL5/Experts/ (or MQL4/Experts/) and paste the file. Restart or compile in MetaEditor.
  3. Go to Tools ➔ Options ➔ Expert Advisors: Check "Allow WebRequest for listed URL" and add your server URL (e.g. http://<your-raspberry-pi-ip>:8000).
  4. Attach the EA to any chart. In the EA inputs, paste your account's API Key (copied above). It will automatically sync trades, balance, and chart candles to your journal!
